# BlendUs API

Backend of the [BlendUs](https://github.com/fjsermun3103/BlendUs) demo: Laravel API and Ollama (local AI models) in one container.
The frontend is hosted on Vercel and the database on Neon. Setup guide: `DEPLOY-FREE.md` in the main repository.
